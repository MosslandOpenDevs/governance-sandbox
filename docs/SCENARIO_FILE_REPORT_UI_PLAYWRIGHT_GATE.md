# Scenario-file report UI Playwright gate

Keep phase one narrow before widening presets or demo polish.

- Start with one JSON or YAML scenario file that reliably generates JSON, Markdown, and HTML reports.
- When the first web demo grows, keep one form, one result card, and one report-download handoff visible at a time.
- Reuse stable labels, deterministic sample data, and step-by-step verification so browser replays can recover from failures without guessing.
