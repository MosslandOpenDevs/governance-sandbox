# Scenario report subject note

Use this note when a scenario fixture should keep one report subject visible in the generated markdown/html bundle.

- Prefer `report.subject` or `report.subjects` inside the scenario-file `report` block.
- Accept top-level aliases like `report_subject`, `report_subjects`, `subject`, `subjects`, `topic`, or `topics` when fixtures need a shorter handoff.
- Keep the subject short enough to read beside report title, subtitle, audience, and owner metadata.
- Treat the subject as report-facing framing, not a replacement for the proposal text.
