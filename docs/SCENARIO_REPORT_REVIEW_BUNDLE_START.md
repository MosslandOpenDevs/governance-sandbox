# Scenario report review bundle start

Use this note when one imported governance scenario already generates the JSON, Markdown, and HTML artifacts needed for review.

## Replay order

1. open one scenario file
2. run one CLI command that writes the full report bundle
3. review the Markdown memo first
4. reopen JSON or HTML only if deeper trace or presentation proof is needed

## Why

This keeps the early governance-sandbox review lane anchored on one replayable scenario-to-report bundle instead of drifting into ad hoc screenshots or copied summaries.

## Small acceptance check

A reviewer should be able to point to one source scenario file and one shared bundle basename without asking for extra shell context.
