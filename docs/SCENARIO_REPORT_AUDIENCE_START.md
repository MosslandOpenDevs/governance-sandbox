# scenario report audience start

Use this note when you need the fastest proof that a scenario file can drive report audience metadata into generated memo artifacts.

Smallest reliable loop:

1. load one JSON or YAML scenario file,
2. set `report.audience` or one documented audience alias,
3. write markdown or html report output,
4. confirm the rendered report keeps the same audience text.

This keeps scenario-file input support and report-generation proof coupled before broader web-demo work.
