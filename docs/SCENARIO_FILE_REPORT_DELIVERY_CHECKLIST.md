# Scenario-file report delivery checklist

Use this checklist when the active slice is still **scenario file input + generated report files**.

## Minimum believable proof

1. Load one JSON or YAML scenario file.
2. Confirm the proposal and stakeholder inputs resolve without manual reshaping.
3. Generate one JSON report plus matching Markdown and HTML outputs.
4. Verify the emitted paths are visible in the CLI result.
5. Keep the result small enough to replay in one command.

This checklist keeps phase-one work focused on reproducible scenario import and readable report delivery before preset expansion or web-demo scope.
