# Web demo form-to-card scope

Use this note when shaping the first governance-sandbox web demo.

- Keep the first slice to one scenario form and one result card.
- The card should expose a clear outcome summary plus report bundle handoff.
- Preserve deterministic replay: stable field names, stable selectors, stable artifact naming.
- If the browser proof fails, repair the smallest broken step before widening the flow.
- Delay multi-screen polish until the single form-to-card path is reproducible.
