# Scenario file + report + web demo phase-one note

Phase one should stay anchored to the same tiny workflow:

1. import one JSON or YAML scenario file,
2. generate the JSON + Markdown + HTML report bundle,
3. reuse the same scenario data in the simple web demo,
4. keep the first result card aligned with the saved report outputs.

This keeps the scenario-file/report foundation ready for the first UI slice without breaking the validation-first contract.
