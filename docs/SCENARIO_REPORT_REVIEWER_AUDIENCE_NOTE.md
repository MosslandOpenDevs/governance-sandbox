# scenario report reviewer audience note

Use this note when one JSON/YAML scenario import already produces a reusable report bundle and you want the primary reviewer audience to stay attached to the generated markdown/html/json artifacts.

## Keep together

- the scenario file,
- the generated report basename,
- and the reviewer audience that should read it first.

## Template

`Scenario report audience: <scenario file> -> <bundle basename> for <reviewer audience> keeps the generated markdown/html/json bundle reviewer-ready.`

## Example

`Scenario report audience: examples/scenario-web-demo.yaml -> treasury-confidence-rehearsal for governance reviewers keeps the generated markdown/html/json bundle reviewer-ready.`
