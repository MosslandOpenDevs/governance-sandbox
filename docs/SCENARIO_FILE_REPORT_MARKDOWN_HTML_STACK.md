# Scenario file report markdown html stack

The first Governance Sandbox proof should keep scenario import and human-readable report output in one replayable path.

Minimum stack:

- one JSON or YAML scenario file
- one generated JSON output for machine checks
- one generated Markdown report for memo review
- one generated HTML report for browser review

If the workflow no longer proves all three report artifacts from the same imported scenario, restore that stack before widening scope.
