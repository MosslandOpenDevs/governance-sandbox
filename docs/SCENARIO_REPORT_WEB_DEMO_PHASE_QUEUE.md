# Scenario Report Web Demo Phase Queue

Current growth order for `governance-sandbox`:

1. **Scenario file input support** (`.json`, `.yaml`, `.yml`, JSON5/JSONC when enabled)
2. **Report generation** with JSON + Markdown + HTML outputs
3. **Stakeholder trait presets** for DAO, delegates, contributors, investors, and community
4. **Web demo** with one clear input form and one result-card oriented output flow
5. **README demo GIF** after the web demo flow is stable

UI follow-up should stay aligned with a result-card-first layout and Playwright-friendly step checks, but only after the scenario/report validation lane is green.
