# Scenario Report Owner + Audience Handoff

Use this note when one governance-sandbox scenario file should generate a report bundle that keeps both audience and owner metadata visible for reviewers.

## Handoff target

- one scenario file
- one generated JSON/Markdown/HTML report bundle
- one quick check that audience and owner metadata stay readable in the report output

This keeps scenario-file input work tied to reviewer-facing report output instead of treating metadata as a hidden JSON-only detail.
